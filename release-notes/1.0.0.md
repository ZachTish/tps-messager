# TPS Notifier 1.0.0

## Release intent

This is the first GitHub release of the existing `1.0.0` plugin for BRAT installation and **Latest**-release tracking. The packaging work adds release metadata without changing shipped runtime behavior, delivery settings, or protocol compatibility.

## Included behavior

- ntfy delivery transport for TPS Controller reminders and direct plugin API calls.
- Safe-by-default disabled transport, manual composer, dry-run diagnostics, guarded callback paths, and mobile-aware modals.
- Private-repository installation through BRAT with a fine-grained GitHub token limited to **Contents: Read-only**.

## Compatibility

- Minimum Obsidian version: `1.10.0`.
- Desktop and mobile are supported.
- No migration is required from the existing `1.0.0` runtime; `obsidian://tps-notifier` remains a compatibility alias.

## Validation

- `npm test`: passed `21/21` tests and its nested production build.
- Required separate `npm run build`: passed TypeScript and esbuild production bundling.
- Test-vault deployment: `[runtime-deploy] target=test ... unchanged`; the final source artifacts are byte-identical to the installed test runtime.
- This release candidate is prepared from the test-vault source and has not been promoted to production by this packaging pass.

## Known limitations

- Private BRAT installs require the GitHub token on each device; never store that token in the vault or repository.
- BRAT does not transfer ntfy settings between devices; delivery remains disabled until configured locally.
- BRAT consumes the standard `main.js`, `manifest.json`, and `styles.css` assets. The additional `styles-ui.css` release attachment is retained for manual-package parity but is not fetched by BRAT.
- Automatic retry/backoff and a rolling delivery log are not implemented.
