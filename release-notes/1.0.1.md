# TPS Notifier 1.0.1

This patch makes notification settings fail-safe under sync, read errors, and rapid edits.

## Changes

- Reloads current plugin data and applies only locally changed fields, preserving synchronized and unknown fields.
- Treats a higher settings schema as read-only and blocks writes after a failed read rather than replacing valid configuration with defaults.
- Persists server and topic edits directly through the durable queue instead of an unload-unsafe timer, and safely retries a write whose failure result was ambiguous.

## Compatibility and validation

- Minimum Obsidian: 1.10.0; desktop and mobile supported; no manual migration.
- Focused settings tests: 6/6 passed; TypeScript and diff checks passed.
- Full declared suite: 25/25 passed. A separate production-mode build deployed byte-identical artifacts to the isolated test vault.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**; Notifier registered normally and no runtime settings file was created or replaced.
- Automatic delivery retry/backoff remains outside this release.
